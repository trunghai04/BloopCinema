## 5. Layout Principles

### Spacing System

**Base Unit:** `8px`

**Spacing Scale:**
- `8px` - Micro spacing between tightly grouped elements (button icon-to-text gaps)
- `16px` - Small spacing between sibling components
- `24px` - Standard spacing between related content blocks
- `32px` - Medium spacing between major sections
- `36px` - Vertical spacing between page sections
- `40px` - Large padding within container cards
- `52px` - Section divider spacing
- `60px` - Page-level vertical rhythm and top/bottom margins

**Usage Context:**
- Micro-interactions and icon spacing: `8px`
- Component-to-component margins: `16px` to `24px`
- Section internal padding: `40px`
- Page section breaks: `52px` to `60px`

### Grid & Container

- **Max Container Width:** `1200px` (inferred for body content)
- **Column Strategy:** Two-column layout for supplementary information (e.g., "Why have I been blocked?" and "What can I do to resolve this?")
- **Gutter Width:** `24px` between columns
- **Section Pattern:** Full-width banner hero (H1 + subtitle), followed by contained body sections with side-by-side FAQ layouts
- **Page Padding:** `40px` horizontal padding on desktop, reduced to `24px` on tablet, `16px` on mobile

### Whitespace Philosophy

Abundant whitespace creates visual hierarchy and reduces cognitive load. The design prioritizes breathing room around typography and interactive elements, with intentional margins between content zones. Large vertical spacing (36–60px) separates distinct sections, while tighter spacing (8–16px) groups related items. This creates a sense of calm and professionalism, suitable for security-focused messaging.

### Border Radius Scale

- **Sharp Corners (`0px`):** All interactive components (buttons, inputs, cards, containers). The flat design approach eliminates rounded corners throughout the system.
- **Fully Rounded (`50%`):** Icon containers and status badges (circles for error marks, success indicators).
- **No Intermediate Radius Values:** System maintains strict adherence to either sharp or fully rounded to preserve visual consistency.

**Shadow Philosophy:**
This design system employs a minimal shadow strategy, prioritizing flat design with occasional subtle elevation. Shadows are used sparingly to indicate interactivity and depth when necessary. The primary approach relies on color, borders, and whitespace rather than shadow depth to establish hierarchy. When shadows are applied, they remain soft and understated, using low-opacity black to avoid visual heaviness. This approach aligns with the security-focused, clean aesthetic where clarity and simplicity take precedence.
